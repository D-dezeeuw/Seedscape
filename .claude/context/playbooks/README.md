# Playbooks

Short, ordered checklists for cross-cutting implementation tasks. Skills load these when triggered.

| Playbook                                       | Use when                                  |
|------------------------------------------------|-------------------------------------------|
| [add-tile-type.md](add-tile-type.md)           | Adding any new tileId (not crop/building) |
| [add-worker-task.md](add-worker-task.md)       | Adding a new worker message type          |
| [wire-new-system.md](wire-new-system.md)       | Adding a new tick-driven sim system       |

For specific content additions:
- New crop → [add-crop skill](../../skills/add-crop/SKILL.md)
- New building → [add-building skill](../../skills/add-building/SKILL.md)
- New biome → [add-biome skill](../../skills/add-biome/SKILL.md)
